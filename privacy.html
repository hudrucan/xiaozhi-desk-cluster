Privacy Policy

Last updated: 2026-11-19

Desk Cluster is a private, single-user application used only by its owner on a home network. It is not offered to the public.

Data accessed. The app requests only the Google Drive scope drive.file. It can read and write only the files that the app itself created in the owner's Google Drive (configuration, sound and memory files for a home voice assistant). It cannot see any other files.

Use and sharing. Data is used only to synchronise the app's own configuration between the owner's home devices. It is not sold, shared with third parties, used for advertising, or used to train AI models. No analytics or tracking are collected.

Storage. OAuth tokens are stored only on the owner's own devices.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
